A macro photograph-style picture of strawberries: three whole glossy
berries with seed pits, shoulder gloss, water droplets and green calyxes,
plus one halved berry in front showing its pale heart core, flesh
striations and seeds in the cut face, on a dark green ground. No text.

## Build

```sh
python3 gen.py        # renders entry.png (1024x1024)
```

## Run

```sh
python3 main.py       # copies entry.png to $MAKEFUN_OUTPUT_DIR (default /output)
```
